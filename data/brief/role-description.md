# Full-Stack Engineer — Systems Conductor

**Full-Time · Remote**

## About Bold Business

Bold Business is an AI-first, delivery-first company building production-grade enterprise software, automation engines, and autonomous agent infrastructure. We build the way modern teams build: our engineers are not syntax-typists but Systems Conductors, who leverage advanced AI-agent developer environments to design, build, test, and ship production software at multiples of traditional manual velocity.

## The Role

We're hiring Full-Stack Systems Conductors to own feature delivery across our flagship TechForce platform — spanning React/TypeScript frontends, Python/FastAPI backends, and robust PostgreSQL data schemas.

You'll own high-impact modules from day one, but your true value lies in your ability to design robust databases, orchestrate complex systems, and lead background coding agents through rigorous, test-driven implementations.

Two principles define how we work, and we hire for both explicitly:

**AI-Agentic Command.** AI coding environments (Cursor, Claude Code CLI, OpenClaw / Hermes Agents / Grokbot / other personal agent harnesses, and custom Model Context Protocol servers) are our native workspace, not a novelty. We expect you to command agents to write boilerplate, scaffold routes, and draft test suites. You provide the system architecture, the security guardrails, and the rigorous critical review. Speed from agents, judgment from you.

**Collaborative by Default.** Every change is strictly peer-reviewed through pull requests. Documentation and automated unit tests ship in the same PR as the code. Blockers get raised early, not discovered at review. We value highly legible, standardized architectures that outlive their author's immediate attention — brilliant work that only its author understands is a liability here, not an asset.

## What You'll Do

- **Architect schema-first features:** design strict API boundaries, typed contracts, and database schemas first, providing the structure background AI agents need to implement features safely
- **Build and secure module workflows:** own recruiter and admin interfaces (screens, tables, profiles, forms, filters, dashboards), REST endpoints, and PostgreSQL relational workflows — with business security and authorization policies strictly enforced at the data layer
- **Establish codebase context:** build and use MCP servers and AST-based dependency graphs to give developer agents standardized, structured access to our repositories
- **Orchestrate quality loops:** set up local testing environments and containerized CI/CD checks where background agents automatically execute test runs, linting, and type validation before any merge
- **Engage directly with stakeholders:** sit with non-technical stakeholders to translate messy operational processes into clean, executable technical requirements — and keep them in the loop as the work progresses
- **Stabilize and maintain the platform:** production defects, small-to-medium gaps, and reporting migration support as Power BI is retired
- **Review and be reviewed:** give and receive pull-request review as a normal working rhythm, with test evidence on every ticket

## Non-Negotiables (Knockout Requirements)

We'll ask you to demonstrate all of the following — come ready with real examples:

1. **Active agentic developer loop.** You've transitioned beyond copy-pasting code blocks from a browser window. You can walk us through your CLI-native agentic loop: how you coordinate agents, what parameters and guardrails you set, and — specifically — a time you caught and patched an LLM hallucination before it shipped. "I've tried Copilot" is not this.
2. **Collaboration you can prove.** A working history of PR reviews given and received, documentation you wrote that someone else actually used, and a time you escalated a blocker early instead of grinding on it alone. We will check for this specifically.
3. **Full-stack competency, production-grade.** Strong React/TypeScript and Python/FastAPI experience on real systems in real use — not tutorials or side scripts.
4. **Database schema and security mastery.** Highly fluent in PostgreSQL — schema design, migrations, indexing, transactional isolation. You understand why hiding a button in React is not an authorization control; authorization is enforced in the data layer.
5. **Clean systems architecture.** You build robust, decoupled state machines (FastAPI, React state, background queues) that gracefully isolate, log, and recover from real-world API and network failures.
6. **Enterprise systems awareness.** You've designed, maintained, or operated within ERP-class platforms (SAP, Oracle, Workday, NetSuite, or comparable) — or can clearly demonstrate how they work and why they matter: integrated data, standardized process, and a single operational source of truth. You'll help build a platform that plays exactly this role, so you need to understand what it replaces and what it must not break.
7. **True Agile and continuous improvement.** Not standup theater — iterative delivery, working software shipped in small increments, retrospectives that actually change how the team works. Come ready to describe a real process improvement you drove based on what a sprint or a failure taught you.
8. **End-to-end micro-project ownership.** You'll run micro-projects through their full lifecycle: planning and requirements gathering with stakeholders, implementation, testing, and maintenance afterward — documenting your work and processes clearly enough that another team member can be trained to support and back up what you built without you in the room. Come ready to walk us through one project you carried from first conversation to steady-state maintenance.
9. **Strong English communication, written and spoken.** You'll operate in a U.S.-based team environment and explain technical decisions to non-technical stakeholders.
